# HANGMAN
About the Project

This is a simple command-line Hangman game developed using Python. The objective is to guess a randomly selected word by entering one letter at a time before running out of lives.

The player starts with 10 lives and loses one life for every incorrect guess.

Features

Random word selection from a predefined word list.

10 chances to guess the correct word.

Displays the current progress of the word.

Tracks previously guessed letters.

Prevents repeated guesses.

Validates user input.

Displays the correct word if the player loses.

Technologies Used

Python 3

Random module

String module

How to Run

Clone or download this repository.

Make sure Python 3 is installed.

Ensure that Words.py is in the same directory as hangman.py.

Run the following command:

python hangman.py

How to Play

Run the program.

A random word will be selected.

Enter one letter at a time to guess the word.

Correct guesses reveal the letters in their respective positions.

Incorrect guesses reduce your remaining lives.

Guess the complete word before your lives reach zero to win!
